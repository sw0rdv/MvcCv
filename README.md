## 📌 Proje Hakkında

Bu proje, kişisel özgeçmiş bilgilerinin dinamik olarak yönetilebildiği, ASP.NET MVC 5 mimarisi kullanılarak geliştirilmiş admin panelli bir CV ve portfolyo uygulamasıdır.

Projenin temel amacı, statik bir CV web sitesi yerine veritabanı destekli, yönetilebilir ve sürdürülebilir bir web uygulaması oluşturmaktır.

Uygulamada **Model-View-Controller (MVC)** mimarisi, Entity Framework ve SQL Server kullanılarak içerik yönetimi ve veri işlemleri gerçekleştirilmiştir.

## 🖥️ Portfolyo Arayüzü

Kişisel portfolyo sayfasında özgeçmiş bilgilerim dinamik olarak ziyaretçilere sunulmaktadır.

**Portfolyo bölümleri:**

- **Hakkımda:** Kişisel bilgiler ve profesyonel profil özeti.
- **Deneyimlerim:** İş deneyimleri ve çalışma geçmişi.
- **Eğitim Hayatım:** Üniversite ve eğitim bilgileri.
- **Yeteneklerim:** Teknik yetkinlikler ve beceri seviyeleri.
- **Hobilerim:** İlgi alanları ve kişisel aktiviteler.
- **Sertifikalarım:** Eğitim ve sertifika bilgileri.
- **Projelerim:** Geliştirilen yazılım projeleri.
- **İletişim:** Ziyaretçilerin mesaj gönderebildiği iletişim alanı.

## 🗂️ Proje Mimarisi

Proje, ASP.NET MVC 5 mimarisine uygun olarak yapılandırılmıştır.

- **Model:** Uygulamanın veri yapılarının ve iş nesnelerinin tanımlanması.
- **View:** Razor kullanılarak kullanıcı arayüzlerinin oluşturulması.
- **Controller:** Kullanıcı isteklerinin karşılanması ve uygulama işlemlerinin yönetilmesi.
- **Entity Framework:** Veritabanı işlemlerinin ORM yaklaşımıyla gerçekleştirilmesi.
- **SQL Server:** İlişkisel verilerin saklanması ve yönetilmesi.
- **Validation:** Form girişlerinin ve zorunlu alanların kontrol edilmesi.

## ⚙️ Yerel Kurulum

Projeyi yerel ortamınızda çalıştırmak için:

1. Repository'yi bilgisayarınıza klonlayın.

   ```bash
   git clone https://github.com/sw0rdv/MvcCv.git
   ```

2. `MvcCv.sln` dosyasını Visual Studio ile açın.

3. NuGet paketlerini yükleyin.

4. SQL Server bağlantı ayarlarını `Web.config` dosyası üzerinden yapılandırın.

5. Gerekli veritabanını ve tabloları oluşturun.

6. Projeyi çalıştırın.
